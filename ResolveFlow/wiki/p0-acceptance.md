# P0 冻结验收

## 数据与边界

`data/eval/p0_acceptance_v1.json`：11个开发者编写的中文合成场景，8个目标理解场景、3个执行流程。
文件在首轮运行前冻结，SHA256为 e451f3b678d23d489ce8938fe0a9a5dfa90584204ef0771ef6a547fc31977e1d。
标签不会发送给模型。目标理解场景不等于最终回答质量验证；流程场景才执行隔离模拟业务。
这不是公开基准，不是真实用户数据。查看失败并据此修复后，此集合成为回归集，不能继续宣称未见测试集效果。
后续新增独立盲测应建立 v2，而不是修改 v1 标准。

## 命令

从仓库根目录：

```bash
PYTHONPATH=ResolveFlow .venv/bin/python ResolveFlow/scripts/run_p0_acceptance.py
PYTHONPATH=ResolveFlow .venv/bin/python ResolveFlow/scripts/run_p0_acceptance.py --live --campaign p0-20260911 --max-calls 60
```

第二条真实计费；同一 campaign 的所有运行和失败请求共享60次调用上限，写盘预留，不会因重启脚本重置。
`--only 场景ID ...` 只复验指定场景；产生新的不可覆盖UUID报告，保留首轮失败。
输入和输出均有大小上限，SDK自动重试关闭；费用未配置计价规则，报告为 null，不等同于免费。
所有订单、确认、审批、退款在临时数据库中由测试操作者按固定剧本执行，不操作用户现有任务。
复合任务和恢复场景中的人工审批由测试替身模拟，不声称真实员工审批通过。

## 指标定义

- expected_outcomes：符合冻结目标或流程验收条件的案例数 / 本次所选案例总数。预算不足未执行不能计成功。
- raw_model_semantics：模型原始目标匹配冻结标签数 / 本次已执行目标理解案例数；服务端校正后的结果另列。
- 流程独立校验：读数据库中的权益、续费及退款状态；检查用户确认关联、越权访问拒绝、过期授权不复用、幂等键不重复。
- latency_ms：自动化测试推进耗时，不包含真实人的思考或审批等待时间，不是线上客服响应指标。
- 调用数和Token来自模型适配器；无法获取的费用为 null。离线模式不报告真实模型语义正确率。

报告包含代码摘要、数据摘要、模型和模式、场景分布、过程状态、错误及服务端校正记录。
既有审批API身份校验、拒绝、过期和重复批准仍由单元/API回归覆盖，不能用这些离线结果冒充真实模型验收。
